Case study: FMCG

The company faced a problem: the product categories in its range had low consumption frequency per user. The following objectives were set:
Developing new user interests
•Increasing the number of target customers
(reducing costs)
•Helping users identify the product they need

Client: Major perfume and cosmetics manufacturer
Main objective:
- Increasing the number of customers
- Helping customers choose products
How Datawave solved it
  • Building an in-product onboarding system
  • Building an event chain that presents the company's offers and leads users to the target action
  • Developing gamification models to create a new user behavior pattern
  • Scoring-based recommendation system (automated rewards for user behavior)
Results:
  • Higher consumption frequency +30%
  • Higher basket value +20%
  • Higher inflow of users with an average check of RUB 5,000 +5%
  • Time to first purchase reduced by 40%

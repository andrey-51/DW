Feature release: website element personalization

The Data Wave team has released a new feature: website element personalization.

Using the no-code builder, Data Wave CDP customers can tailor banners, sections and individual blocks to user segments. Flexible settings and a convenient, intuitive interface make the system easy to work with.

  • Website sections
  • Individual blocks

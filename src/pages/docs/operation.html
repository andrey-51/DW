Information required to operate the software

System requirements

Deployment of the software suite is subject to three main groups of requirements:

  • workstation requirements for users of the suite (developers)
  • qualification requirements for users of the suite (developers)
  • requirements for the server infrastructure in which the suite will be deployed

User workstation requirements

The workstation must meet the following requirements:

  • Operating system:
    • Linux
    • MacOS
    • Windows

User qualification requirements

A user of the suite must have the following competencies:

  • Knowledge of marketing fundamentals
  • Knowledge of the fundamentals of designing user interaction logic (optional)
  • Knowledge of algorithms (optional)

Server infrastructure requirements

To deploy the suite in production mode, you need to prepare a server that

must meet the following specifications:

Hardware requirements (recommended):

  • CPU-2
  • Memory: 128 GB DDR4
  • Swap: 2GB
  • Storage:
    • 2 × 480 GB SATA SSD
    • 2 × 1920 GB SATA SSD

Software description

This software is program code whose purpose is the collection and aggregation of user information, including communication with the user.

Objectives:

  • Communication
  • Analysis of user actions after communication
  • Communication planning
  • Provision of components

Purpose:

  • Communicate with users via chatbots, social networks, messaging apps and push messages.
  • Create recommendations for products, services and rate plans on the website, in the mobile app and in partner integrations.
  • Analyze behavior and predict customer needs based on ML models.
  • Create your own personalized loyalty programs, promotions, bonus systems and gamification of the interaction process.
  • Build offers personalized for each customer: product, price, timing and bonus
  • Enrich data on customers and their needs, including through third-party DMP providers.

Key software functions

Main functions

  • Receiving audience data from multiple sources.
  • Managing customer identity data.
  • Supporting real-time customer segmentation.
  • Providing customer data to other systems.

Data ingestion. CDPs extract customer data from multiple sources (for example, transactional systems, online behavior, call center, demographic data or POS).

Identity management. CDPs resolve customer identities across multiple channels, most of them using deterministic matching and profile stitching with identifiers provided in the incoming data. A CDP creates and maintains a persistent customer identifier.

Segmentation. CDPs enable marketers to create and maintain universal omnichannel audience segmentation using unified data in the CDP.

Data delivery / activation. CDPs facilitate the activation of information and of the single customer profile created in the CDP by providing connectors and APIs for other marketing technologies.

Technologies and programming languages used to implement the Software/Services

Since the principles of how customer data technologies work are by now well established in the market, we have identified the system principles that matter to the client:

•Technology popularity: demand among other companies

•Technology prevalence: the number of professionals on the labor market skilled in using it

•Language development and support: long-term support.

The project is built on a microservice architecture, which was chosen to enable continuous improvement of the system's modules:

•Security and ease of testing

•Ability to improve the system without changing its core structure

•Ability to use various technologies: flexibility of support.

The following technologies and programming languages are used to implement the Software/Services:

  1. ClickHouse: a system for building analytics. ClickHouse responds very quickly to analytical queries on data updated in real time, so it can be used in interactive applications. The system can scale to tens of trillions of records and petabytes of data. Using ClickHouse opens up possibilities that were previously hard even to imagine: it is possible to store the entire data stream without pre-aggregation and quickly get reports broken down by any dimension.
  2. PostgreSQL: a powerful open-source object-relational database system with more than 35 years of active development that has earned a strong reputation for reliability, feature robustness and performance.
  3. Redis: a server-side data structure store. It is used as a cache in front of the “real” PostgreSQL database. A Redis-based cache helps improve performance. It makes efficient use of the speed of in-memory data access and eases the data-processing load on the application's central database.
  4. MongoDB: in MongoDB, data is stored in unstructured form, as special documents. It is used for working with non-relational databases.
  5. React: a system for simplifying the process of building large applications. React is geared toward a component-based approach to development. React addresses application performance, making the application faster and less resource-intensive through the use of a virtual DOM.
  6. Python: used for back-end development. It is in high demand among company employees and is a popular language among the target audience, as well as among analysts in companies' R&D departments

Detailed description of platform modules and their characteristics

Module: customers

Module objective:

Searching for and selecting users for communication

Features:

  1. Searching for customers in the database
  2. Creating selections from the customer database
  3. Viewing customer data
  4. Displaying data on an individual customer
  5. Displaying available technical data on customers

    1. Dynamic selection: a customer selection whose membership is updated over time
